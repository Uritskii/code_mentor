# Code Mentor — наставник по коду (ДЗ 1)

Агент, который находит ошибки в решении студента, но не выдаёт готовый код,
а ведёт к решению подсказками. Запоминает типичные ошибки в профиль студента.

## Структура
- `agent.py` — цикл агента (ReAct): рассуждение → действие → наблюдение, лимит шагов
- `tools.py` — 3 инструмента с pydantic-схемами, валидацией и обработкой ошибок
- `providers.py` — смена провайдера модели через переменную PROVIDER
- `tasks.json` — учебные задачи со скрытыми тестами (синтетические данные)
- `main.py` — консольный чат
- `spec.md` — спецификация проекта

## Запуск
```bash
pip install -r requirements.txt
python main.py
```

## Архитектурные решения
- Эталонные ответы тестов не возвращаются ни одним инструментом — утечка
  решения невозможна архитектурно, а не запретом в промпте.
- Ошибки инструментов возвращаются как данные {"error": ...}, агент не падает.
- `record_mistake` — действие с побочным эффектом, идемпотентное.
- Провайдер модели меняется конфигом, код не трогаем.

## Стражи в коде (правила, которые промпт гарантировать не может)
- **Только код студента.** Harness извлекает код из сообщения студента,
  `run_tests` отклоняет любой другой код — модель не может прогнать тесты
  на собственном «исправленном» варианте и присвоить успех студенту.
- **Код прислан — тесты обязательны.** Если в сообщении есть блок кода,
  а модель отвечает без вызова run_tests, harness не отдаёт ответ и
  возвращает модель в цикл с напоминанием.
- **Лимит шагов.** После max_steps агента останавливает harness, а не модель.
- **Трассировка.** Каждый вызов инструмента печатается в лог.

## Известные ограничения (честно, для README)
- Запуск кода студента — subprocess с таймаутом, без полной изоляции
  (для прода нужна песочница/контейнер).
- Память — только история текущего диалога; профиль ошибок — в JSON-файле.
- Локальная модель (qwen3:8b) может давать слишком прямую подсказку первого
  уровня. Правило уровней подсказок реализовано промптом; надёжное соблюдение
  будет проверяться eval-набором (лекция 6) — метрика «доля подсказок без
  утечки решения». На облачных моделях поведение стабильнее.
- Нет итогового отчёта по профилю — следующие ДЗ.
